# 🧠 My Personal AI Vault

A lightweight, local AI-powered knowledge assistant built with Streamlit and Google Gemini.

## Features
* Clean, interactive web UI built in Python.
* Direct integration with Google's Gemini model.
* Allows users to query custom notes and documents on the fly.

## Tech Stack
* **Python**
* **Streamlit** (Frontend UI)
* **Google GenAI SDK** (Gemini API)
